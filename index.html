Impor CSV

Masukkan banyak barang sekaligus ke bulan yang sedang dibuka. Siapkan file dengan baris pertama sebagai judul kolom, lalu satu baris per barang.

Format kolom

  • nama (wajib)
  • kategori sembako, lauk, sayur, bumbu, minuman, camilan, rumah, diri, atau other
  • jumlah angka, default 1
  • satuan kg, liter, pcs, dll., default pcs
  • harga per satuan dalam rupiah, default 0

Contoh isi file

nama,kategori,jumlah,satuan,harga
Beras pandan wangi,sembako,5,kg,75000
Telur ayam,lauk,2,kg,30000
Sawi hijau,sayur,3,ikat,5000
Sabun cuci piring,rumah,1,botol,12000

Gunakan koma (,) sebagai pemisah. Titik koma (;) juga bisa dipakai. Nilai yang mengandung koma ditulis dalam tanda kutip.
